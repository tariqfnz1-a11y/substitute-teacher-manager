# Substitute Teacher Manager — GitHub Pages

## Deploy
1. Create a new GitHub repository, for example `substitute-teacher-manager`.
2. Upload these four files:
   - `index.html`
   - `style.css`
   - `app.js`
   - `timetable.js`
3. Open GitHub → Settings → Pages.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your public Pages address.

No Python or server is required.

## Important
The application stores approved substitution plans in the browser's localStorage. This means the current version is a single-device prototype. For a multi-campus, multi-user production system, a database/login backend should be added later.
